\begin{abstract}
\textsc{Sparse-Matrix Vector Multiplication} (SpMV) is a computational kernel encountered in many scientific applications. It has an inherently low computational intensity, and its performance is memory-bound. This thesis evaluates the performance metrics of five increasingly selective communication strategies for SpMV in a shared and distributed memory hybrid environment. Experiments were conducted on single-socketed and dual-socketed multicore systems across various configurations. Findings show that reducing the communication volume yield better performance on a single node. In multi node setups, the findings show that performance is impacted by the communication volume, but that other factors such as network and hardware characteristics also play a large role in performance.

Due to its low computational intensity, SpMV performance is limited by memory bandwidth, making parallelization across shared and distributed memory systems essential. This thesis investigates the impact of five increasingly selective communication strategies on SpMV performance in hybrid OpenMP/MPI environments. Experiments were conducted on dual- and single-socket multicore systems using various memory configurations. Results show that while lower communication volumes often improve performance on single nodes, in multi-node setups, network and hardware characteristics can outweigh communication volume in determining performance.
