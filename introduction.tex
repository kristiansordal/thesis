\chapter{Introduction}
Sparse-Matrix Vector Multiplication (SpMV) is a fundamental computational kernel in many scientific computing applications. It appears in a broad range of domains, such as iterative solvers for partial differential equations, machine learning, and when simulating physical systems. As a result, optimizing the performance of SpMV, both on CPUs and GPUs remains a widely researched topic. SpMV lends itself nicely to paralellization, but it is a kernel with an inherently low computational intensity, and its performance is therefore memory-bound.
\medskip

In this thesis, five distinct communication strategies are introduced. These communication strategies successively become more sophisticated. The simplest being a strategy that communicates the entire local part of the dense \(x\) vector to each other rank. Then there are two separator-based strategies, which involve communicating only the set of boundary elements that induce data dependencies between nodes. Finally, the two most sophisticated communication strategy involves communicating only the elements that induce data dependencies to the node where this data dependency occurs, with the last of these two being fully memory-scalable.
\medskip

Experiments have been conducted to test the impact that each communication strategy have on the performance of parallell SpMV. The experiements have been conducted using a test set of eight different sparse matrices, and various parallel configurations across three different multicore architectures available on Simulas eX\(^{3}\) machine. To facilitate inter-node communication, one MPI rank has been placed on each compute node (or on each socket if the compute node is dual-socketed), and shared memory parallelization with OpenMP has been used for intra-node communication.
